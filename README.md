# Efeito Parallax

Este repositório contém um projeto de efeito Parallax utilizando HTML, CSS e JavaScript. O efeito Parallax cria uma ilusão de profundidade ao fazer com que elementos se movam em velocidades diferentes durante a rolagem da página.

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## Funcionalidades
O projeto inclui diferentes tipos de efeitos Parallax:

1. **Parallax1**: Altera o tamanho do background e a opacidade do título ao rolar a página.
2. **Parallax3**: Move imagens de forma suave conforme a rolagem.
3. **Parallax4**: Aplica um efeito de rotação em um card conforme a posição do mouse.
